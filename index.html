HOW CYBER//GRID WORKS

01 // SKILL TREE NAVIGATION

Click any of the 8 sector nodes in the top diagram to load its steps. Glowing solid lines mean a prerequisite sector is 100% mastered.

02 // CONCISE NOTES + REAL EXAMPLES

Tap any unlocked step to read its field note, real-world attack/defense scenario, and curated external YouTube playlists.

03 // VIDEO SERIES TRACKING

Check off each video/playlist as you finish it. Your completion percentage updates live per step, per sector, and globally.

04 // 90% MASTERY GATE & WEAKNESS DIAGNOSTICS

Score at least 90% on a step's exam to unlock the next step. Larger topics automatically have more questions. If you fail, the engine pinpoints the exact sub-topics you lack and shows why each missed answer was wrong. Passed steps can be re-examined anytime.

05 // PERMANENT SAVE & BACKUP

All progress saves permanently in your browser's local storage. Use EXPORT to download a JSON backup file and IMPORT to restore it on any device.
